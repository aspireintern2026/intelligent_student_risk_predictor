Problem

Educational institutions identify struggling students only after exam results. By then, it's often too late to intervene effectively.

Students failing unexpectedly
High dropout rates
No early monitoring system

AI Solution

Analyzes behavioral and academic patterns early to flag at-risk students with probability scores and actionable recommendations.

Early risk detection
Explainable AI (SHAP)
Intervention suggestions

ML Models

Trains multiple classifiers and selects the best based on F1 score and ROC-AUC, with special focus on minimizing false negatives.

Logistic Regression (baseline)
Random Forest (~86% acc)
XGBoost (~91% acc)
System Architecture Student Data Input ↓ data_pipeline.py → Generate + clean + scale features ↓ train_model.py → Train LR / RF / XGBoost, save best ↓ predict.py → Build features → run model → return risk ↓ backend/main.py → FastAPI REST (POST /predict, /predict/batch) ↓ frontend/index.html → Teacher Dashboard (this page)
